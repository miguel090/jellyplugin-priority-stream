Live TV Priority

When a priority user starts a Live TV channel and the tuner is busy with a different channel, the other session is stopped and its tuner released before the priority stream is opened.

When off, Live TV behaves exactly as without the plugin.

Priority users

These users can take over the tuner. Everybody else keeps the default behavior.

Message to the preempted session

{user} is replaced with the priority user's name.
0 lets the client decide. Not every client honours this.

Normal users when the tuner is busy

When every tuner is busy with other channels, a normal user's request is refused straight away and they are told which channel(s) are on, so they can join one of those.
{user} = who is watching, {channel} = the channel(s) they can watch instead.

Exempt channels

The plugin ignores these channels completely: requesting one never kicks or blocks anyone, people watching one are never kicked, and they don't count as using the tuner. Use this for channels that don't go through the limited connection.

What can be preempted

E.g. the living-room TV is stopped when the same user starts another channel on the phone.
When on, an in-progress recording on another channel is cancelled. Off by default.
When off, a priority user who is watching is never kicked by another priority user.

Timing

How long the priority request waits for the tuner to be released before continuing anyway.
Extra pause after the tuner is released so Dispatcharr / the IPTV provider can drop the old connection.

Advanced

Recommended. Turn off only if a client requests PlaybackInfo for channels it does not play.
0 = use the tuner count from the Live TV tuner settings (1 if unknown). Preemption only happens when every tuner is busy.
Log every decision at Information level. Preemptions are always logged.
